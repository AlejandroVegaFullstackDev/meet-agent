# ADR-0012: La app usa la IA del usuario, sin modelos locales
**Estado:** aceptada · 2026-10-27 · reemplaza ADR-0002 (Whisper local) para la app de escritorio y matiza ADR-0008 (local primero)

**Contexto:** MeetAgent pasó a ser público (MIT) para cualquiera. Descargar modelos de Hugging Face y transcribir en CPU complica la instalación y depende del equipo. La mayoría de la gente ya paga una IA (Claude, OpenAI, DeepSeek, Gemini) o tiene un modelo propio (Ollama o LM Studio con Qwen).

**Decisión:**
- Puerto `IChatModel` en el Core (una vuelta: instrucciones + contenido → texto, con esquema JSON opcional). Adaptadores en `MeetAgent.Ai`:
  - `AnthropicChat` con el SDK oficial (`Anthropic`): salida estructurada con el esquema y fallback del servidor (`fallbacks: "default"`) en los modelos que lo admiten. Modelo sugerido `claude-opus-5-5`.
  - `OpenAiCompatibleChat` para OpenAI, DeepSeek, Gemini (endpoint OpenAI), OpenRouter, Groq y servidores propios. Pide `json_object`; si el servidor no lo acepta, reintenta con el esquema solo en las instrucciones.
- Transcripción de la app con `CloudTranscriber` (`/v1/audio/transcriptions`, `verbose_json` → `json` si el modelo no da tiempos): OpenAI, Groq o un servidor propio. Claude y DeepSeek no transcriben audio; quien solo tenga esos usa la extensión (los subtítulos de Meet ya traen el texto).
- «Puente» de cuentas: **OpenRouter** con OAuth PKCE (login con Google/GitHub, callback a `localhost:3000`) da una key para todos sus modelos. Sin cuenta conectada, la alternativa es una API key o la IA del usuario por MCP, que lee la reunión y guarda su análisis con `guardar_analisis`.
- **El usuario no instala nada** (2026-10-28). Se quitaron `AccountInstaller` y el diálogo «Instalar y conectar»:
  - **ChatGPT:** «Continuar con ChatGPT», el flujo oficial *Sign in with ChatGPT* para apps de código abierto (`ChatGptLogin`, `ChatGptPlanChat`; https://developers.openai.com/siwc/token-sharing-open-source). Registro dinámico con `client_id=dynamic_agent_client` + `agent_name_hint=MeetAgent` + `ext_agent_host_id` (`urn:uuid`, uno por equipo); PKCE; callback en `http://127.0.0.1:1455/auth/callback` (otro puerto si está ocupado); ID token validado con el JWKS de OpenAI (firma, emisor, audiencia, vencimiento, nonce). Inferencia en `POST /v1/responses` con `store: false` y `stream: true`, contra el plan del usuario (hace falta ChatGPT Plus o Pro). Sesión en `data/chatgpt.json`: tokens con DPAPI, el `client_id` emitido y el id del equipo se conservan al cerrar sesión. Reemplaza al binario de Codex.
  - **Claude:** Anthropic no ofrece login de terceros y, desde abril de 2026, la suscripción no cubre herramientas de terceros. Si Claude Code ya está en el equipo se sigue usando; si no, la tarjeta ofrece OpenRouter o una API key.
  - **Google (Gemini):** Google no da a terceros el cupo de la cuenta del usuario. Si Gemini CLI ya está en el equipo se usa; si no, la tarjeta pide la key gratis de AI Studio.
  El login de Claude y Gemini se abre en el navegador sin ventana de consola y se consulta cada 2 s hasta 5 minutos. En Windows los ejecutables se buscan solo con extensión (`claude.cmd`, `.exe`; el `claude` sin extensión de npm es un script de bash), y los `.cmd` de npm se lanzan directo a su `.exe`/`node` porque `cmd.exe` corta los argumentos en el primer salto de línea.
- **Reutilizar la sesión que ya hay en el equipo** (2026-11-21). Antes de abrir un login se busca una sesión válida; si existe, «Conectar» es instantáneo y no abre el navegador:
  - **ChatGPT:** la sesión propia de MeetAgent en `data/chatgpt.json` (`ChatGptLogin.ResumeAsync`). Si el access token venció se refresca con el refresh token; si OpenAI ya no acepta la sesión (refresh inválido o 401) se borran los tokens y se pasa al login normal.
  - **Claude:** la del propio Claude Code, preguntándole con `claude auth status --json` (sus credenciales viven en `~/.claude/.credentials.json` en Windows y Linux; en macOS, en el llavero). Claude Code refresca su token al usarse.
  - **Google (Gemini):** la de Gemini CLI, si existe `~/.gemini/oauth_creds.json` (`%USERPROFILE%\.gemini\` en Windows). Gemini CLI la refresca al usarse.
  - MeetAgent **no lee ni copia los tokens de otras apps**: a Claude Code y Gemini CLI se les pregunta por su sesión y se usan a través de su propio programa. En particular **no se reutiliza `~/.codex/auth.json`** de Codex: sus tokens se emitieron para el cliente de Codex (usarlos sería hacerse pasar por Codex) y su refresh token rota, así que refrescarlo desde MeetAgent cerraría la sesión de Codex del usuario. Para ChatGPT se usa siempre el flujo oficial para apps de terceros.
  - Los inicios de sesión de ChatGPT y OpenRouter se pueden **cancelar** desde la tarjeta: se libera el puerto del callback y la tarjeta vuelve a su estado inicial. La página del callback solo dice «Listo» si llegó el código; con `access_denied` u otro error dice que no se conectó.
  - `ia.json` y `chatgpt.json` se escriben de forma atómica (temporal + reemplazo); en Linux/macOS el archivo nace con permisos 600.
- `MeetingAnalyzer`: estadísticas calculadas en el equipo (exactas, sin tokens) + transcripción → JSON (`resumen`, `decisiones`, `tareas`, `temas`, `preguntas_abiertas`, `riesgos`, `tono`). Si no cabe en una llamada (60 000 caracteres por defecto), toma notas por tramos y las une. Se guarda en la tabla `insights` (una fila por reunión; puerto `IInsightsStore`).
- Configuración en `data/ia.json`. API keys con DPAPI en Windows; en Linux/macOS, archivo con permisos 600.

**Consecuencias:**
- Sale de la app la dependencia de Whisper.net y de `models/`. La CLI (`live`, `bench`) y el `SttServer` siguen con Whisper para quien quiera montar su servidor propio.
- El audio y la transcripción se envían al proveedor que el usuario elige, y solo a ese. El diálogo de consentimiento lo dice; la grabación y el texto siguen guardándose solo en el equipo.
- El costo lo paga cada usuario a su proveedor. Las estadísticas no gastan tokens, y el análisis automático al terminar se puede apagar.
